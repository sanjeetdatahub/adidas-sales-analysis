## Skill Level: Intermediate

This project reflects an intermediate-level data analytics workflow using Python, Pandas, data cleaning, EDA, and business-focused dashboarding.

## Overview

This project analyzes Adidas sales performance in the United States using retail transaction data. The goal is to understand revenue trends, product profitability, sales channel efficiency, and geographic performance.

## Business Questions Answered

- Which products generate the highest sales and margin?
- Which sales channel performs best?
- Which regions and states contribute the most revenue?
- What are the seasonal patterns in sales?
- How can the business improve profitability and inventory planning?
